# Report

Final deliverable: **one consolidated PDF** covering Milestones 01-03, **max 35 pages** including the cover (references and appendix excluded).
File name: `IT3060HCI2026_Milestone03_Group<number>` (ours: `IT3060HCI2026_Milestone03_GroupWE_15`).

Put drafts here (e.g. `draft.docx`) and screenshots in `evidence/`.

## Required sections

1. Cover page: module, Milestones 01-03 (Final Report), title, group number and name, member table with ID, name, workload
2. Executive summary
3. Milestone 01 summary (problem, stakeholders, research, requirements)
4. Milestone 02 summary (sketches, wireframes, low-fi, hi-fi)
5. Tech stack selection and justification (`docs/ARCHITECTURE.md`)
6. System/app architecture overview
7. Implementation details and screenshots (including deviations from the prototype, `docs/DEVIATIONS.md`)
8. Traceability matrix: requirements → prototype → implementation → test cases
9. Functional test cases and results (`testing/functional/`)
10. Usability testing plan, execution, results (`testing/usability/`)
11. Issues identified and fixes
12. Gantt chart (overall schedule)
13. Conclusion and lessons learned
14. References, then Appendix (full test logs, extra screenshots, recording links, code excerpts)
