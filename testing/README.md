# Testing

The assignment requires functional test cases (core features and CRUD), a traceability matrix, and usability testing with at least 5 participants.

| File | Purpose |
|------|---------|
| `functional/TEST_CASES.md` | Test case log. Each member writes cases for their own interfaces |
| `functional/TRACEABILITY_MATRIX.md` | Requirement → prototype → implementation → test cases |
| `usability/USABILITY_PLAN.md` | Tasks, participants, metrics, issue log |

Evidence (screenshots, recordings) goes in `report/evidence/`. Large videos: upload to Google Drive and link them.

Run automated tests from `mobile/` with `npm test`.
